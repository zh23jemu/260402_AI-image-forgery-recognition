# 程序源码与数据集说明

## 1. 说明

本项目源码包用于配合论文《面向泛化检测的AI伪造图像多模型识别研究》进行程序复核与实验复现。

源码包默认只包含以下内容：

- `fsd/`：FSD 相关训练、评估与联合训练代码
- `stay_positive/`：Stay-Positive 相关训练与测试代码
- `tools/`：本文补充实现的分析、导出、绘图、论文与答辩辅助脚本
- `run_*.slurm`：服务器训练与导出脚本
- `README.md`：项目总说明
- 本说明文档

源码包默认**不包含**以下大体积或不可直接分发内容：

- 原始数据集
- 训练日志
- 本地虚拟环境 `.venv`
- 模型权重与 checkpoint
- 分析中间产物与临时渲染文件

这样处理的目的是让交付包更轻量，也避免直接分发第三方数据与模型文件。

## 3. 数据集来源与下载地址

### 3.1 GenImage

本文 FSD 主线实验主要使用 `GenImage` 数据集，覆盖 ADM、BigGAN、GLIDE、Midjourney、Stable Diffusion、VQDM 等生成器类别。

来源与下载地址：

- 官方仓库：<https://github.com/GenImage-Dataset/GenImage>
- 论文地址：<https://arxiv.org/abs/2306.08571>
- Google Drive：<https://drive.google.com/drive/folders/1jGt10bwTbhEZuGXLyvrCuxOI0cBqQ1FS?usp=sharing>
- 百度网盘：见官方仓库 README，提取码通常为 `ztf1`

本项目中的目录组织方式可参考：

- [data/GenImage/README.md](/C:/Coding/260402_AI-image-forgery-recognition/data/GenImage/README.md)

### 3.2 Stay-Positive / Latent Diffusion 检测评估数据

Stay-Positive 相关实验使用作者提供的评估数据与扩展数据入口。

来源与下载地址：

- 官方仓库：<https://github.com/AniSundar18/AlignedForensics>
- Stay-Positive 论文地址：<https://arxiv.org/abs/2502.07778>

## 4. 建议的复现顺序

推荐按以下顺序准备：

1. 下载并整理 `GenImage` 数据集
2. 下载 FSD 官方 checkpoint
3. 下载 Stay-Positive 预训练模型与评估数据
4. 配置 FSD 与 Stay-Positive 运行环境
5. 先跑单模型评估，再跑联合训练或分析脚本
